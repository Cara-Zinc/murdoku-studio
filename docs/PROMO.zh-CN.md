# 小红书图文草稿

建议用 9 张竖图，画面占主要篇幅，每张只讲一件事。重点展示玩家怎样用工具推理。不要把它描述成自动读题、自动破案或官方产品。配图使用项目的原创练习案件和原创大地图测试场景。

想试试的话，项目里有原创练习题👇
https://github.com/Cara-Zinc/murdoku-studio

独立爱好者工具，非官方。欢迎告诉我哪里用着不顺手。

## 桌面包上线后的替换句

等 Windows 包和 Mac 包都完成验证并发布到 Releases 后，在正文加入：

> Win / Mac 下载后解压，双击就能开，不用配开发环境。

末图可替换为：**下载 → 解压 → 双击开始**，并补上 Releases 链接：
https://github.com/Cara-Zinc/murdoku-studio/releases

当前草稿不声称两个平台都已发布。Mac 本地包是预览构建，Windows 仍需运行对应平台的构建任务。

## 发布前核对

- 用原创题配图；宣传图片不附带官方 PDF 或完整官方题目。
- 配图与当前 UI 一致，不写「所有物品都自动识别」或「自动解出所有题」。
- 如果介绍桌面包，先验证下载链接、启动、PDF 导入、导出与重开后的存档恢复。
- 小红书正文里保留完整项目地址，末图也写地址，方便读者手动搜索。
